# CLAUDE.md - System Rules & Tool Usage Guidelines

## Critical Tool Usage Rules

- **Always Prefer Surgical Edits (`Edit`)**: When updating existing files, YOU MUST USE THE `Edit` TOOL to modify only the target function or block. 
- **NEVER Overwrite Entire Files (`Write`)**: DO NOT use `Write` to replace or rewrite entire existing files. Replacing whole files causes data loss and timeouts.
- **Preserve Surrounding Structure**: Keep all surrounding HTML, CSS, JavaScript, imports, and layout structure completely intact during edits.
